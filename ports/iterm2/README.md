# Fall for iTerm2

A warm, low-blue color preset for [iTerm2](https://iterm2.com). 🍂

The ANSI palette uses Fall's colors and has no true blue: the blue slot is Fall's purple.

## Install

1. Download [`Fall.itermcolors`](https://raw.githubusercontent.com/ThatXliner/fall/main/ports/iterm2/Fall.itermcolors).
2. Open **iTerm2 › Settings › Profiles › Colors**.
3. Open **Color Presets…**, choose **Import…**, and select the file.
4. Open **Color Presets…** again and choose **Fall**.

Double-clicking the file also imports it.

## Build

`Fall.itermcolors` is generated from the [Fall palette](../../palette/fall.json). Do not edit it by hand. From the repository root, run `npm run build`.
